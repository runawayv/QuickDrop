# QuickDrop
Передача файлов между ПК и телефоном по локальной сети. Без облаков, кабелей и регистрации.

Запусти приложение на компьютере, отсканируй QR-код телефоном — откроется страница, где можно скачать файлы с ПК или отправить свои.

Возможности
Drag & drop файлов и папок с ПК
Приём файлов с телефона через браузер
Подключение по QR-коду или ссылке (Wi-Fi сеть)
Прогресс, скорость и история передач
Тёмная/светлая тема, русский/английский язык
Иконка в трее, автозапуск с Windows
Скачать
Готовый exe — в разделе Releases.

Сборка из исходников
Нужны Visual Studio 2022+ с рабочей нагрузкой «.NET для настольных приложений».

git clone https://github.com/runawayv/QuickDrop.git

Открыть `QuickDrop.sln` → `F5`.

## Технологии

C#, .NET, WPF, QRCoder.
