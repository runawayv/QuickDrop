## 🚀 Что такое QuickDrop?

**QuickDrop** — небольшое Windows-приложение для удобной передачи файлов между компьютером и телефоном через **Wi-Fi, Ethernet или мобильную точку доступа**.

Никаких аккаунтов, облачных сервисов и проводов.

Просто:

**Запустил → отсканировал QR-код → передавай файлы.**

Телефон открывает обычную веб-страницу в браузере, поэтому устанавливать приложение на него не нужно.

* 📁 **Drag & Drop** — перетаскивай файлы и папки прямо в окно

## 🖥️ Как это работает?

```text
             Локальная сеть
                  │
        ┌─────────┴─────────┐
        │                   │
     💻 ПК              📱 Телефон
        │                   │
   QuickDrop           Браузер
        │                   │
        └─────── ↔ ────────┘
```

QuickDrop запускает локальный веб-сервер на компьютере.

Телефон подключается к нему через Wi-Fi и получает веб-интерфейс для передачи файлов.

**Файлы не загружаются в интернет и не проходят через сторонние серверы.**

## 📦 Установка и запуск

### 1. Установи .NET

Установи **.NET Desktop Runtime 10 (x64)**:

[.NET 10 Downloads](https://dotnet.microsoft.com/download/dotnet/10.0?utm_source=chatgpt.com)

> Если необходимый Runtime уже установлен, этот шаг можно пропустить.

### 2. Скачай QuickDrop

Скачай последнюю версию из **Releases**:

[QuickDrop Releases](https://github.com/runawayv/QuickDrop/releases?utm_source=chatgpt.com)

Распакуй архив в любую папку.

### 3. Запусти

Запусти:

```text
QuickDrop.exe
```

После запуска отсканируй QR-код камерой телефона.

Готово — можно передавать файлы. 🚀

> ⚠️ Папка `www` должна находиться рядом с `QuickDrop.exe`. Она содержит веб-интерфейс для телефона.

## 🔐 Приватность

QuickDrop рассчитан на работу **внутри локальной сети**.

Файлы передаются напрямую:

```text
ПК ←──────────→ Телефон
```

а не через облачный сервер:

```text
ПК ──→ ☁️ Сервер ──→ Телефон
```

Для работы QuickDrop интернет **не нужен**.
